# Одиссей — тема WordPress (тестовый репозиторий для админки)

Копия темы `odissey` с боевого сайта [gpodyssey.ru](https://gpodyssey.ru), снятая по FTP.
Используется как тестовый контур для разработки расширенной админ-панели
(редактирование фото, текстов, оружия, мероприятий, УЦ, контактов через wp-admin/ACF),
прежде чем изменения переносятся на прод.

## Структура

- `theme/` — файлы темы (PHP-шаблоны, `assets/styles.css`, `assets/main.js`)
- Папка `assets/photo` с изображениями НЕ включена (не нужна для разработки логики админки, только раздувает репозиторий)

## Статус

В разработке. Прод не трогаем, пока блоки не проверены здесь.
