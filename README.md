# Одиссей — тема WordPress (тестовый репозиторий для админки)

Копия темы `odissey` с боевого сайта [gpodyssey.ru](https://gpodyssey.ru), снятая по FTP.
Используется как тестовый контур для разработки расширенной админ-панели
(редактирование фото, текстов, оружия, мероприятий, УЦ, контактов через wp-admin/ACF),
прежде чем изменения переносятся на прод.

## Посмотреть живую админку (GitHub Codespaces)

Прямо в браузере, без установки чего-либо на свой компьютер:

1. Наверху страницы репозитория на GitHub нажать зелёную кнопку **«Code»**
2. Вкладка **«Codespaces»** → **«Create codespace on main»**
3. Подождать 1–3 минуты — контейнер сам поставит WordPress, ACF, тему и создаст
   тестовые страницы (см. `.devcontainer/setup.sh`)
4. Когда появится уведомление о порте **8899** — открыть его (или вкладка
   **«PORTS»** внизу → напротив 8899 нажать на иконку глобуса)
5. **Чтобы ссылкой можно было поделиться** — в той же вкладке **PORTS**
   правой кнопкой по порту 8899 → **Port Visibility → Public**
6. Логин в wp-admin: `odyssey_admin` / `Odyssey#Demo2026!`
   (добавить `/wp-admin/` к адресу, который дал Codespace)

Дальше открыть любую страницу (напр. «Тир») в редакторе — под текстом сразу видны
блоки **«Арсенал (оружие)»**, **«Фотоблоки»**, **«Прайс»** — можно добавить оружие,
загрузить фото, увидеть результат сразу на сайте.

Стенд временный: если codespace остановить (или он потухнет от простоя), потом при
повторном открытии `start.sh` сам поднимет сервер заново на том же порту.

## Структура

- `theme/` — файлы темы (PHP-шаблоны, `assets/styles.css`, `assets/main.js`)
- `.devcontainer/` — автонастройка демо-стенда для Codespaces (WordPress + ACF +
  SQLite вместо MySQL, чтобы не поднимать отдельную базу)
- Папка `assets/photo` с изображениями НЕ включена (не нужна для разработки логики
  админки, только раздувает репозиторий) — фото в демо можно загружать прямо
  через wp-admin, чтобы попробовать вживую
